# 01: Make the Panorama Map the primary interaction surface

**What to build:** Replace the persistent left Trail Catalog and right floating inspector with a compact search control above a dominant Panorama Map, automatic Trail focusing, and readable Trail details below the map.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Ordinary interface labels and controls use a substantially more readable type scale; no core interaction depends on 7–10px text.
- [ ] Search occupies only a compact control area above the map and reveals matching Trail results progressively.
- [ ] Selecting from search or clicking a mapped Trail keeps the stable Trail URL, highlights the Trail, and focuses the map around it.
- [ ] Trail detail content is rendered below the map rather than over Trail geometry.
- [ ] Desktop and 390px mobile layouts remain usable without horizontal overflow.
- [ ] Existing bilingual, evidence, map zoom/pan, keyboard, and direct-link behavior remains intact.
