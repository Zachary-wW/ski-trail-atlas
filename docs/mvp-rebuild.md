# 富龙地图 MVP 重构

更新：2026-09-24。当前阶段：**东侧描摹已获用户继续推进确认，全图候选描摹正在逐区域复核**。

这是当前执行入口，取代 `.scratch/` 中三轮旧规格的任务顺序。
旧应用仍保留作为回归基线，不代表已满足本计划。

## 产品目标

先完成富龙，再以相同数据契约接入其他雪场：

- 完整雪道图，保留用户原图的形状、相对位置、分叉、汇合和设施位置。
- 每条雪道有文字档案与对应视频；未知内容不能伪造补齐。
- 起终点路线规划与地图共用分段，路线连续且连接关系可追溯。
- 网页优先，桌面地图旁展示详情，手机保持可搜索、可点选、无横向溢出。

视觉样式可以重新设计，山体的功能结构不能重新编排。
图示结构一致不等于测绘精度、实时开放或现场导航保证。

## 本轮范围

完成一个开发环境专用的富龙全图结构复核样板：

- 高清原图、叠加校准、独立线稿三种对照模式。
- 全图、山顶、中央/公园、西侧 L3、东侧 B 区、初学区分区查看。
- 雪道与参考要素选择、透明度、交叉口标记、缩放与拖动。
- 东侧已接受的节点/分段保持原路径；允许按用户确认修复旧原图断口，
  并明确记录修正来源。新增全图分段与线稿、点击和参考信息共用。
- 未知连接、规划线、索道与魔毯保留明确状态，不猜测路线连接。
- 原图仅本地使用，样板不替换现有生产页面。

该样板仍不是完整 MVP，不包含已审核的雪道介绍/视频、正式全图路由或多雪场入口。
它也不是最终视觉稿；先验证结构，避免以美化掩盖几何偏差。

## 必须经过的验收关口

1. **原图身份一致**：尺寸与摘要见[校准说明](research/fulong-reference-calibration.md)。
2. **逐段视觉复核**：每段中心线、起终点和分叉在同坐标叠加中可检查；
   标签遮挡处明确标出，不以锚点数量代替沿线检查。
3. **交互一致**：点击、选中、高亮均使用同一段几何。
4. **连接一致**：演示路线相邻分段共享实际标注节点；不存在的连接不补线。
5. **用户确认**：用户接受局部结构精度后，才扩展整图并确定量化容差。

东侧已通过第 5 项的继续推进关口；全图仍需逐区验收，量化容差尚未约定。
不要将“代码完成”“测试通过”写成“1:1 还原完成”，视觉认可也不等于通行核验。

### 2. 富龙全图候选描摹复核（当前）

按用户第二轮反馈修订后的候选清单：63 个图示分段、35 组雪道标号、
3 项参考要素与 9 条交通设施标记。区分雪道、连接道、索道/魔毯、
规划线和身份待定要素。当前逐区域复核形状、分岔、汇合和端点，保留
来源版本与核验状态；这些数量不是已发布库存或测绘结论。

已知待核验项包括 B16 未定位、C3 重复编号、E1 规划参考线、
中央/西侧未编号连接，以及 B12/B11 等新增线的方向。

2026-09-24 用户修正：D1/D2/A9/A10 在 L2 上站共享节点；重描 B15/B13
与中央弯道、B11/A7 的分岔汇合；C3/C6 交叉处分段；原 F8/F9 邻道接入
教学区。C11/C12 按用户所述“去年已开放”记录为 2025 年已开放的用户反馈，
具体雪季未核验；F8/F9 仅按“可能取消”暂隐藏线稿，原图历史标注保留。

连通性按无向图检查，除独立教学小区外，所有已描摹雪道处于一个连通分量。
这不表示可逆向滑行；实际候选路线仍有方向约束。新增和修正段仍不发布为
可通行路线。地面曲线交叉检查排除架空索道及 E1 规划参考线。

### 3. 内容与规划闭环

接通雪道选择 → 文字/参数/视频 → 起终点规划 → 同图分段高亮。
每条雪道介绍、关键特点、进出口、视频匹配及来源单独审核。
视频明确区分逐道、区域和雪场级匹配；视频占位不算内容完成。
生产路线只使用达到发布要求的连接，不能直接发布样板候选图。

### 4. 多雪场与视觉整理

以 `resortId` 选择雪场内容包，地图/详情/规划接收数据，不各自 import
富龙单例。保留现有 React + TypeScript + Vite，暂不引入登录、CMS、
实时导航或能力推荐。完成结构后再统一地形、线条、标签与样式。

## 保留与替换

保留搜索/直链、来源与缺失值机制、双语基础和可复用路由算法。
替换旧手工几何/拓扑双表；例如旧 B10 的线与图边端点不一致。
不把旧“33 条”作为全图固定上限，也不因原图多出标号就自动发布。

原有 ADR 0001/0002/0004 的证据与方向约束继续适用。
[ADR 0005](adr/0005-reference-native-segment-pilot.md) 明确新样板与旧图的迁移关系。
